MY RESET — DOPAMINE DIARY

Состав
- index.html, style.css, script.js — приложение.
- manifest.json — описание устанавливаемого приложения (PWA).
- service-worker.js — кеш оболочки и офлайн-загрузка.
- icons/ — иконки приложения.

Запуск для предварительного просмотра
Откройте index.html в современном браузере. При открытии через file:// приложение работает как обычный локальный сайт, но PWA-установка и service worker недоступны.

Следующий этап: PWA
1. Разместить содержимое папки My_Reset на HTTPS-хостинге (важно: не сам ZIP, а распакованные файлы).
2. Открыть опубликованный HTTPS-адрес в Chrome на Android.
3. Дождаться первого открытия, чтобы service worker установил офлайн-кеш.
4. В меню Chrome выбрать «Установить приложение» или «Добавить на главный экран».

Данные и перенос
Данные хранятся локально в браузере. Перед переходом с локального index.html на HTTPS-версию откройте Настройки → Скачать JSON. После публикации откройте приложение на HTTPS и импортируйте этот JSON. Локальное хранилище file:// и HTTPS — разные хранилища.

Резервная копия
Настройки → Скачать JSON. Импорт проверяет структуру перед заменой данных; текущая версия предварительно сохраняется в локальную резервную копию.

Офлайн
После первого успешного открытия опубликованной HTTPS-версии service worker кеширует HTML, CSS, JavaScript, manifest и иконки. Google Fonts требуют интернет при первой загрузке; при отсутствии сети используются резервные системные шрифты.

Конфиденциальность
Приложение не использует сервер, аккаунт или аналитику. Данные остаются в хранилище браузера на устройстве.
